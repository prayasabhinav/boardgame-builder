# The tentative blocks, put into the templates

Written 6 November 2026. Four agents read each template's rules and added a tentative block where the rules plainly do what the block describes, or where a proposal names the game (rule in the brief they followed). A slot that holds one block was changed only where a tentative block names the game's rule more exactly. One line per changed template: file | added | replaced | the rule that shows it. Chance alone decides was put in a chance-or-skill slot in three templates (bingo, war, Royal Game of Goose); it is a core mechanic, so it was moved there and *mostly chance* put back. Every line here is a proposal: the templates enter games.json only when Prayas approves each.
